# The sandbox wheelhouse.
#
# This file is the boundary of what a generated app can import. The sandbox
# network is `internal: true` (SANDBOX_AND_SCALE_PLAN.md §3.1), so there is no
# route to PyPI and a `pip install` inside the container cannot succeed; every
# package a generated app might plausibly need has to be baked in here instead.
#
# Adding something here is how you make a dependency available. The cost is
# image size and a rebuild, so add what generated apps realistically import and
# nothing speculative.
#
# Keep the Python version identical to backend/Dockerfile. A 3.11 sandbox and a
# 3.12 app meant 3.12-only syntax passed the pipeline and failed the sandbox.
